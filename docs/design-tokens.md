# 「삼한지」 디자인 토큰 · 아트 디렉션 스펙

v1.0 — 전략맵 프로토타입에서 추출한 실측 값 기준

이 문서의 용도는 세 가지임.
1. **Claude Code에 붙이는 컨텍스트** — 새 화면을 만들 때마다 같은 얼굴이 나오게 함
2. **AI 이미지 생성 프롬프트의 고정 블록** — 초상화·이벤트 CG가 UI와 따로 놀지 않게 함
3. **판단 기준** — 새 요소를 추가할 때 "이게 이 시스템에 맞나"를 가르는 근거

## 0. 아트 디렉션 한 줄

> **조선 고지도(대동여지도)의 조형 언어로 그린 삼국시대 전략 지도.**
> 사실적 렌더링이 아니라 **먹선과 기호로 기록된 지도**이며, 그 위에 게임 데이터가 얹힌다.

### 지켜야 할 원칙 3가지

**① 완성도는 개별 품질이 아니라 일관성에서 나온다.**
에셋 하나를 잘 만드는 것보다, 모든 에셋에 같은 팔레트·같은 후처리·같은 선 굵기를 먹이는 것이 완성도를 만든다. AI로 생성한 초상화가 제각각이어도 동일한 프레임·색보정·질감을 일괄 적용하면 한 세트로 읽힌다.

**② 형태가 정보를 담는다. 색은 보조다.**
거점은 **모양이 등급**, **색이 세력**이다. 색맹이거나 축소된 상태에서도 모양만으로 도성/산성/항구를 구분할 수 있어야 한다. 새 기호를 추가할 때도 이 원칙을 따른다.

**③ 장식은 넣지 않는다. 모든 그래픽 요소는 의미를 가진다.**
산맥 기호는 예쁘라고 있는 게 아니라 지형 장애물을 표시한다. 강의 겨울 색 변화는 도하 가능을 뜻한다. 의미 없는 요소는 뺀다.

## 1. 색 (Color)

### 1.1 기반색 — 지(紙)와 묵(墨)

| 토큰 | HEX | 역할 |
|---|---|---|
| `--ji` | `#DDD0B2` | 한지 바탕. 육지, 패널 배경 |
| `--ji-deep` | `#CFC09C` | 한 단계 어두운 지. 게이지 트랙, 길 노반 |
| `--ji-edge` | `#B5A47E` | 최외곽 테두리 |
| `--hae` | `#B9C3BC` | 바다 |
| `--meok` | `#241F1A` | 먹. 본문, 윤곽선, 반전 버튼 배경 |
| `--meok-mid` | `#554C40` | 담묵. 보조 텍스트, 길 선 |
| `--meok-cap` | `#5A5143` | **캡션 전용.** 8~10px 작은 라벨 |
| `--meok-thin` | `#8A7E6C` | **테두리 전용.** 텍스트에 쓰지 말 것 |
| `--jinsa` | `#A83232` | 진사(주사). 선택 표시, 경고, 개발 한계선 |
| `--su` | `#4E7480` | 수(水). 강, 항로 |
| `--su-ice` | `#CBD3CD` | 결빙 상태의 강 |
| `--panel` | `rgba(221,208,178,.96)` | 떠 있는 창 배경 |

> **`--meok-thin`과 `--meok-cap`의 구분이 중요함.** 둘 다 회갈색이지만 `--meok-thin`(#8A7E6C)은 지 배경 위 대비가 2.60:1로 **텍스트에 쓰면 안 되는 값**이다. 테두리·구분선에만 쓴다. 작은 캡션 텍스트는 반드시 `--meok-cap`(5.10:1)을 쓴다.

### 1.2 세력색

오방색과 실제 유물에서 따왔다. 임의로 바꾸지 말 것 — 각각 근거가 있다.

| 세력 | HEX | 배지 글자색 | 근거 |
|---|---|---|---|
| 고구려 | `#26485C` | `#F2EADA` | 북방 현무, 짙은 군청 |
| 백제 | `#73315A` | `#F2EADA` | 백제 왕실 자주 |
| 신라 | `#A8862B` | `#241F1A` | 금관의 금 |
| 가야 | `#4A6B5A` | `#F2EADA` | 청동 녹청 (철의 나라) |

**배지 글자색 규칙**: 세력색 위에 글자를 얹을 땐 대비 4.5:1을 넘는 쪽을 쓴다. 신라 금색만 밝은 글자와 2.87:1로 미달이라 **먹색 글자**를 쓴다. 나머지 셋은 밝은 글자(7.5~8.1:1).

### 1.3 대비 검증 결과

| 조합 | 대비 | 판정 |
|---|---|---|
| 먹 본문 on 지 | 10.68:1 | AA 통과 |
| 담묵 보조 on 지 | 5.51:1 | AA 통과 |
| 캡션 on 지 | 5.10:1 | AA 통과 |
| 진사 on 지 | 4.34:1 | 대형 텍스트·아이콘만 |
| 지 on 먹 (반전 버튼) | 10.68:1 | AA 통과 |

**알려진 예외 — 신라 금색 마커.** 지 배경 위 2.25:1로 비텍스트 대비 3:1에 미달한다. 다만 모든 마커에 `--meok` 윤곽선(10.68:1)이 둘러져 있고 **형태가 1차 정보**이므로 식별에는 문제없다. 금색을 포기하면 "금관의 나라"라는 근거를 잃으므로 유지하되, 신라 관련 UI에서 색만으로 정보를 전달하지 않는다.

## 2. 타이포그래피

### 2.1 서체

| 용도 | 서체 | 웨이트 |
|---|---|---|
| 전부(제목·본문·지명) | **Noto Serif KR** | 400 / 600 / 900 |
| 숫자·데이터 | **JetBrains Mono** | 400 / 600 |

**명조 계열은 협상 대상이 아니다.** 고딕으로 바꾸는 순간 고지도 성격이 사라지고 일반 웹앱이 된다. 폴백은 `'Batang', serif`.

**숫자에 모노스페이스를 쓰는 이유**: 자원 수치가 매 턴 바뀌는데 폭이 흔들리면 UI가 떨린다. `font-variant-numeric: tabular-nums`를 함께 건다. 명조(역사) + 모노(게임 데이터)의 대비 자체가 "이건 사료가 아니라 시스템"임을 말해준다.

### 2.2 크기 스케일

| 역할 | 크기 | 자간 | 비고 |
|---|---|---|---|
| 바다 라벨 (西海) | 26px | .42em | 지도 위 장식적 라벨 |
| 거점명 (상태창) | 22px | .07em | weight 900 |
| 로고 (三韓志) | 16px | .24em | weight 900 |
| 연도 숫자 | 15px | — | 모노 |
| 자원 수치 | 13.5px | — | 모노, tabular |
| 도성 지명 (지도) | 12.5px | — | weight 900 |
| 버튼 | 11.5px | .06em | |
| 일반 지명 (지도) | 11px | — | |
| 본문·캡션 | 10.5px | .12~.2em | |
| 힌트 | 9.5px | — | `--meok-cap` |
| 자원 라벨 (穀 곡물) | 8px | .24em | `--meok-cap` |

**자간 규칙**: 작을수록 넓게 준다. 8~11px 라벨은 `.2em` 이상, 큰 제목은 `.07~.24em`. 한자 단독 표기(西海, 東海)는 `.42em`까지 벌려 고지도의 여유를 낸다.

### 2.3 지명 표기 — 시그니처

지도의 거점명은 **세로쓰기**한다. 이것이 이 게임 지도의 가장 알아보기 쉬운 특징이다.

```
<text class="lbl"><tspan x="14" dy="0">평</tspan>
                  <tspan x="14" dy="11">양</tspan>
                  <tspan x="14" dy="11">성</tspan></text>
```
- 글자 간격: 일반 11px, 도성 12.5px
- 노드 기준 좌우 14px 오프셋 (`lp: 'l' | 'r'`로 방향 지정)
- **외곽선 처리 필수**: `paint-order: stroke; stroke: var(--ji); stroke-width: 2.8` — 지도 위 어떤 배경에서도 읽히게 함

## 3. 기호 체계 (Iconography)

### 3.1 거점 — 모양이 등급, 색이 세력

| 유형 | 모양 | SVG | 크기 |
|---|---|---|---|
| 도성 | 이중 사각 | `rect 11×11` + `rect 18×18 (fill:none)` | 18px |
| 대성 | 원 | `circle r=6` | 12px |
| 산성 | 삼각 | `M 0 -7.5 L 7 5 L -7 5 Z` | 14px |
| 항구 | 마름모 | `M 0 -7.5 L 6.5 0 L 0 7.5 L -6.5 0 Z` | 15px |

- 채우기 = 세력색, 윤곽선 = `--meok` 1.4px
- 선택 시 윤곽선을 `--jinsa` 2.6px로 교체
- **줌과 무관하게 화면상 크기 일정**: 각 노드에 `scale(1/k)` 역보정을 건다

### 3.2 산맥

능선 폴리라인 위에 삼각 기호를 일정 간격으로 자동 배치한다. 손그림 느낌을 위해 높이·폭·간격에 결정적 변주를 준다.

```
간격 10.5px (±22% 변주) / 높이 8.0px (±34%) / 폭 5.6px (±28%)
스타일: fill:none, stroke:--meok 1.2px, opacity .78
```

**채우기를 넣지 말 것.** 지 색으로 채우면 배경과 같아져 밀집 구간에서 완전히 사라진다(실제로 겪은 문제).

### 3.3 길

육로는 **두 겹**으로 그려 길처럼 보이게 한다.

| 레이어 | 색 | 굵기 | 패턴 |
|---|---|---|---|
| 노반 (아래) | `--ji-deep` | 4.5px | 실선 |
| 노면 (위) | `--meok-mid` | 1.4px | `5 3.5` 파선 |
| 수로 | `--su` | 1.5px | `1.5 5` 점선 |
| 폐쇄 수로 | `--jinsa` | 1.5px | `1.5 8`, opacity .4 |

**직선 금지.** 모든 길은 격자 A* 경로탐색으로 생성해 지형을 따른다. 육로는 육지만, 수로는 바다만 지난다. Catmull-Rom 스무딩 시 **장력 계수 1/11**을 쓴다 — 기본값 1/6은 급커브에서 해안선 밖으로 부풀어 나간다.

### 3.4 SVG 선 공통 규칙

**모든 stroke에 `vector-effect: non-scaling-stroke`를 건다.** 확대해도 선 굵기가 화면상 일정하게 유지된다. 이게 없으면 6배 확대 시 해안선이 뭉개진다.

| 요소 | stroke | width |
|---|---|---|
| 육지 윤곽 | `--meok` | 1.1 |
| 강 | `--su` | 1.7 |
| 호수 | `--su` | 0.8 |
| 산맥 | `--meok` | 1.2 |

## 4. 레이아웃 — 창(窓) 시스템

지도는 화면 전체를 쓰고, UI는 그 위에 **떠 있는 독립 창**으로 얹는다. 사이드바로 지도를 자르지 않는다.

```
공통 창 스펙
  배경: --panel (rgba(221,208,178,.96))
  테두리: 1.5px solid --meok
  그림자: 3px 4px 0 rgba(36,31,26,.18)   ← 블러 없는 오프셋 그림자(판화 느낌)
  머리: 6px 10px, 하단 1px solid --meok-thin, cursor:move
  머리 제목: 10.5px / .28em / weight 600 / --meok-cap
```

- 모든 창은 머리를 잡고 **이동 가능**
- 닫기 버튼은 18×18px, 테두리만 있는 사각
- 배치: 상단=국력, 좌상=줌, 우상=거점, 좌하=사초, 우하=범례

### 창 목록과 역할

| 창 | 역할 | 닫기 |
|---|---|---|
| 국력 표시줄 | 연/계절, 자원 5종, 턴 종료 | 불가 |
| 거점 | 선택 거점의 개발 게이지·명령 | 가능 |
| 사초 史草 | 사건 로그 | 가능 |
| 범례 | 세력별 거점 수 | 불가 |
| 줌 | ＋/－/전체 | 불가 |

## 5. 모션

**절제가 기본이다.** 전략게임은 정보 밀도가 높아 움직임이 많으면 피로하다.

| 대상 | 값 |
|---|---|
| 게이지 채움 | `width .35s ease` |
| 버튼 호버 | `background/color .15s` |
| 로그 진입 | `translateY(-3px)` + fade, `.35s` |
| 강 결빙 전환 | `stroke .5s` |
| 마커 호버 | stroke-width만 변경 (크기 변화 없음) |

`prefers-reduced-motion: reduce`에서 **전부 비활성화**한다.

## 6. AI 이미지 생성용 프롬프트 블록

초상화·이벤트 CG 생성 시 아래 블록을 **매번 고정으로** 붙인다. 스타일 변주를 막는 것이 목적이다.

### 6.1 공통 스타일 블록 (영문)

```
STYLE: Korean Three Kingdoms era (4th-7th century CE), stylized illustration
derived from Goguryeo tomb murals (Muyongchong, Anak Tomb No.3) — flat planes,
confident ink outlines, limited palette. NOT photorealistic, NOT anime,
NOT Chinese or Japanese historical styling.

PALETTE (strict):
  parchment ground #DDD0B2, ink outline #241F1A, diluted ink #554C40,
  cinnabar accent #A83232, water blue-grey #4E7480
  faction accent — pick ONE: #26485C (Goguryeo) / #73315A (Baekje)
                            / #A8862B (Silla) / #4A6B5A (Gaya)

TREATMENT: aged hanji paper texture, subtle vertical fiber grain,
matte finish, no gloss, no lens effects, no modern lighting.

COMPOSITION: bust or three-quarter, centered, plain ground, no background scene.
```

### 6.2 고증 참조 (반드시 참조 이미지로 첨부)

AI 모델은 삼국시대 복식을 모른다. 텍스트만으로는 중국풍·조선풍·일본풍이 섞여 나온다. 아래를 **참조 이미지로 물려야** 한다. 전부 공공 영역이다.

- 고구려: 무용총·안악3호분·쌍영총 고분벽화 (점무늬 저고리, 절풍, 개마무사 갑주)
- 백제: 금동대향로, 무령왕릉 출토품, 서산 마애삼존불
- 신라: 금관, 토우, 기마인물형 토기
- 가야: 철제 갑주, 판갑, 청동기

### 6.3 후처리 (일관성의 핵심)

원본이 조금씩 달라도 **동일한 후처리를 일괄 적용**하면 한 세트로 읽힌다. 배치 스크립트로 자동화할 것.

```
1. 색보정 — 위 팔레트로 톤 매핑 (채도 -15%, 웜톤 +5%)
2. 한지 텍스처 오버레이 (multiply, opacity 14%)
3. 테두리 프레임 — 1.5px #241F1A, 안쪽 여백 6px
4. 비네팅 — 가장자리 8% 어둡게
5. 출력 규격 통일 (초상화 512×640, 이벤트 CG 1024×576)
```

### 6.4 초상화 등급 전략

300명을 전부 잘 만들려 하면 프로젝트가 죽는다.

| 등급 | 인원 | 방법 |
|---|---|---|
| 1급 | 20~30명 | 외주 또는 공들인 AI + 수동 보정 |
| 2급 | 50명 | AI 생성 + 후처리 |
| 3급 | 나머지 | 실루엣 + 세력 문양 + 관직색 **프로그래밍 생성** |

## 7. 하지 말 것 (Anti-patterns)

이 시스템을 깨뜨리는 것들. 새 화면을 만들 때 점검한다.

- ❌ **고딕/산세리프 사용** — 순식간에 고지도 성격이 사라진다
- ❌ **`--meok-thin`으로 텍스트 표시** — 대비 2.60:1, 읽히지 않는다
- ❌ **길을 직선으로 연결** — 산과 바다를 관통한다
- ❌ **산 기호에 지 색 채우기** — 배경과 같아져 사라진다
- ❌ **`vector-effect` 누락** — 확대 시 선이 뭉개진다
- ❌ **색만으로 정보 전달** — 반드시 형태나 라벨을 함께 쓴다
- ❌ **그라디언트·블러 그림자·둥근 모서리** — 이 시스템에는 없다. 그림자는 오프셋만, 모서리는 직각
- ❌ **이모지·현대적 아이콘 세트** — 한자 1글자(穀·財·鐵·兵·船·農·商·城)를 쓴다
- ❌ **의미 없는 장식 요소 추가**

## 8. Claude Code에 붙이는 요약 블록

새 화면 작업 시작 시 아래를 프롬프트에 그대로 붙인다.

```
[삼한지 디자인 시스템]
서체: Noto Serif KR (제목·본문), JetBrains Mono (숫자, tabular-nums)
색: 지 #DDD0B2 / 지-깊 #CFC09C / 바다 #B9C3BC
    먹 #241F1A / 담묵 #554C40 / 캡션 #5A5143 / 테두리 #8A7E6C
    진사 #A83232 / 수 #4E7480
세력: 고구려 #26485C, 백제 #73315A, 신라 #A8862B, 가야 #4A6B5A
      (신라 배지만 글자색 #241F1A, 나머지는 #F2EADA)
형태: 직각 모서리, 그라디언트 없음, 오프셋 그림자 3px 4px 0 rgba(36,31,26,.18)
      테두리 1.5px solid #241F1A
자간: 작은 라벨일수록 넓게 (.2em 이상), 한자 단독은 .42em
아이콘: 한자 1글자 사용, 이모지 금지
모션: .15~.35s, prefers-reduced-motion에서 전부 비활성화
원칙: 형태가 정보를 담고 색은 보조. 장식 요소 추가 금지.
```
