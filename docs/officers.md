## 로스터 구성 방침

한국 삼국시대는 중국 삼국지와 달리 **기록에 남은 인물이 절대적으로 적다.**
『삼국사기』·『삼국유사』를 다 훑어도 이름과 최소한의 행적이 남은 인물은
200명 남짓이고, 그중 다수는 "누가 어느 해에 어느 성을 쳤다" 한 줄이 전부다.

그래서 **고증에만 매이지 않고 재료를 넓혔다.**

| 출전 | 인원 | 내용 |
|---|---|---|
| 삼국시대 사료 | 187 | 삼국사기·삼국유사·일본서기·묘지명·금석문 |
| 후삼국·발해 | 21 | 고려사·신당서 |
| 설화·야사 | 27 | 삼국유사 설화편, 민간 전승 |
| 가상 | 65 | 실제 성씨 구조로 생성 |

**실명 인물이 235명**이다. 초안(150명 실명 + 150명 가상)보다 크게 나아졌다.

### 후삼국을 넣은 이유

후삼국은 압축 시나리오에 **구조적으로 딱 맞는다.** 후백제·후고구려(태봉)·
신라가 그대로 삼국이기 때문이다.

- **후백제** (견훤·신검·능환·아자개) → 백제
- **후고구려·고려** (왕건·궁예·유금필·신숭겸) → 고구려
- **발해** (대조영·대무예·장문휴) → 고구려 *(고구려 계승국)*
- **신라 말** (장보고·최치원·경순왕) → 신라

덕분에 원년 최정예 명단이 **광개토대왕·김유신·왕건·근초고왕·을지문덕·
주몽·대조영·장보고**가 됐다. 700년을 넘나드는 올스타 대진이다.

**장보고는 특히 수군 시스템과 맞물린다** — 청해진의 해상왕에게
`navy`·`naval_trade`·`sea_route` 특기를 줬다. 발해 장문휴(등주 기습)도
수군 장수다.

### 설화 인물

주몽·해모수·금와왕 같은 건국신화 인물부터 처용·수로부인·연오랑세오녀·
지귀·천관녀 같은 설화 인물까지 넣었다. `source`에 "(설화)"로 표시해뒀으니
고증 모드에서 걸러내기 쉽다.

**안시성주는 「양만춘」 하나로 통일했다.** 정사에 이름이 없다는 문제는
`source` 필드에 "통칭(조선후기 문헌)"으로 남겨뒀다.

## 등급 체계

| 등급 | 인원 | 성격 | 능력치 | 초상화 |
|---|---|---|---|---|
| **1급** | 65명 | 실존·핵심. 능력치를 하나하나 수기 지정 | 상한 없음 (최고 98) | 공들일 대상 |
| **2급** | 85명 | 실존. 사료에 등장하나 기록이 소략 | **상한 88** | AI 생성 + 후처리 |
| **3급** | 150명 | 가상. 시대·세력별 실제 성씨 구조로 생성 | **상한 80** | 실루엣 자동생성 |

**등급 상한이 중요하다.** 초안에서는 상한이 없어서 자동생성된 내물왕이
지력 95·매력 95, 온조왕이 정치 99를 받아 을지문덕·김유신과 어깨를 나란히
했다. 수기로 공들여 지정한 인물이 항상 정점에 서야 게임이 납득된다.

디자인 토큰 문서의 **초상화 등급 전략**과 그대로 맞물린다. 300장을 다
그리려 하지 말고 1급 65명에만 집중하면 된다.

## 데이터 구조

```json
{
  "id": "eulji",
  "name": "을지문덕",
  "faction": "goguryeo",
  "tier": 1,
  "histAppear": 590, "histRetire": 618,
  "age": 46, "lifespan": 74, "ruler": false,
  "role": "general",
  "stats": { "lead": 96, "war": 78, "int": 97, "pol": 82, "chr": 80 },
  "skills": ["flood_attack", "scheme", "ambush"],
  "loyalty": "loyal",
  "source": "삼국사기",
  "note": "612년 살수에서 수의 대군을 무너뜨림"
}
```

| 필드 | 설명 |
|---|---|
| `tier` | 1/2/3. 초상화 예산 배분과 밸런스 상한의 기준 |
| `histAppear` / `histRetire` | **역사 모드용** 실제 활동 연도. 압축 모드에서는 쓰지 않음 |
| `age` | **압축 모드용** 원년 시작 나이. 음수면 아직 태어나지 않음 |
| `lifespan` | 사망 나이. `age + 게임연차 > lifespan`이면 은퇴 |
| `ruler` | 세력 시작 군주 여부 (세력당 1명) |
| `role` | general(무장) / civil(문관) / royal(왕족) / monk(승려) / artisan(장인·악사) |
| `stats` | 통솔·무력·지력·정치·매력 (코에이 5능력) |
| `loyalty` | loyal(충의) / ambitious(야심) / mercenary(실리) — 등용·배신 판정에 씀 |
| `source` | 사료 근거. 삼국사기 / 삼국유사 / 묘지명 / 일본서기 / 가상 등 |
| `note` | 한 줄 행적. 게임 내 인물 설명에 그대로 쓸 수 있음 |

## 압축 시나리오 — 700년을 50년으로 접었다

### 왜 압축했나

코에이 삼국지가 꽉 차 보이는 이유는 인물이 많아서가 아니라, **184~234년
50년 남짓한 창 안에 1,000명이 동시에 살아 있기 때문**이다.

한국 삼국시대는 기원전 57년부터 668년까지 700년이 넘는다. 300명을 실제
연도대로 흩뿌리면 어떤 시점에도 20~60명밖에 남지 않아 거점 76개를 채울 수
없다. 초안이 정확히 그랬다.

그래서 **역사 연도는 보존하되, 게임용 나이를 따로 부여**했다.
광개토대왕(391년)과 김유신(629년)은 실제로 238년 떨어져 있지만,
압축 시나리오에서는 각각 29세와 22세로 동시에 등장한다.

이건 고증 훼손이 아니라 장르의 관행이다. 삼국지 시리즈의 가상 시나리오,
노부나가의 야망의 올스타 모드가 같은 방식이다. 대신 `histAppear` /
`histRetire`를 남겨뒀으므로 **역사 모드도 언제든 만들 수 있다.**

### 인구 곡선 (캠페인 50년)

| 게임연차 | 고구려 | 백제 | 신라 | 가야 | 계 |
|---|---|---|---|---|---|
| 원년 | 76 | 65 | 76 | 36 | **253** |
| 10년 | 81 | 66 | 76 | 37 | 260 |
| 20년 | 79 | 68 | 71 | 40 | 258 |
| 30년 | 66 | 56 | 57 | 32 | 211 |
| 40년 | 38 | 30 | 38 | 18 | 124 |
| 50년 | 20 | 18 | 14 | 11 | 63 |

시나리오당 35~62명이던 것이 **253명**이 됐다. 거점 76개에 인물 229명이면
성마다 장수를 배치하고도 여유가 있다.

30년차까지 210명대를 유지하는 것은 **차세대 인원**이 캠페인 중간중간
성인(16세)이 되어 합류하기 때문이다. 이 층이 얇으면 40년차부터 인물이
말라 게임이 빈다(초안에서 겪은 문제).

50년차에 91명까지 줄어드는 것은 남은 과제다. 근본 해결은 **자녀 출생
시스템**이고, 이건 데이터가 아니라 게임 로직이 할 일이다. 우선은
캠페인을 30~40년 안에 끝내도록 승리 조건을 잡는 편이 낫다.

### 원년 배치

**군주 4인** — 광개토대왕(고구려) · 근초고왕(백제) · 진흥왕(신라) · 김수로(가야)

세력별 최정예:

| 세력 | 원년 주요 인물 |
|---|---|
| 고구려 | 광개토대왕(29) 왕건(41) 을지문덕(46) 주몽(36) 대조영(34) 양만춘(31) |
| 백제 | 근초고왕(38) 성왕(31) 견훤(34) 무령왕(31) 계백(36) 흑치상지(28) |
| 신라 | 김유신(22) 진흥왕(33) 장보고(38) 이사부(48) 김춘추(31) 김인문(20) |
| 가야 | 김수로(44) 이진아시(37) 허황옥(33) 정견모주(40) |

**세력 균형** (원년 상위 10인 능력합): 고구려 4260 · 신라 4120 ·
백제 4064 · 가야 3500. 고구려가 가장 강하고 가야가 가장 약한 것은
기획서의 세력 설계(고구려=정복국가, 가야=도전 난이도)와 맞는다.

**김유신을 22세로 둔 것은 의도적이다.** 원년 능력치 총합 2위이면서 나이가
가장 어리므로, 캠페인 내내 살아남아 후반을 지배한다. 기획서의 화랑도
성장 시스템과 맞물리는 서사다.

**가문 관계도 세대 간격으로 보존했다.**

- 김무력(61) → 김서현(44) → 김유신(22) → 원술(캠페인 22년차 성인)
- 연개소문(41) → 연남생(17) → 연남건(1년차 성인)
- 광개토대왕(29) → 장수왕(5년차 성인)

차세대로 대기 중인 주요 인물: 사다함·관창(1년차), 장수왕(5년차),
문무왕(8년차), 온조왕(8년차) 등.

### 연도 표기 제안

압축 시나리오에서 "642년"처럼 서기를 쓰면 광개토대왕과 김유신이 함께
있는 것이 이상해진다. **압축 모드는 「원년(元年)」부터 세고, 역사 모드에서만
서기를 쓰는 것**을 권한다.

## 가상 인물 이름은 어떻게 만들었나

무작위 조합이 아니라 **각 나라의 실제 성씨 구조**를 썼다.

- **백제** — 대성팔족(사택·연·해·진·목·백·협·국) + 왕성 부여씨.
  한국민족문화대백과사전에 따르면 사씨는 본래 사택씨이고, 협씨와 목씨는
  목협씨에서 갈라졌다. 이 구조를 그대로 반영했다.
- **고구려** — 왕성 고씨 + 을·명림·연·해·송·목·우·주·창 등 사서 등장 성씨
- **신라** — 왕성 3성(김·박·석) + 6부 성씨(이·최·손·정·배·설)
- **가야** — 김·이 계열

이름 요소도 실존 인물에서 뽑되, **왕명과 유명인의 전체 이름은 제외**했다.
초안에서 "부여초고", "국비류" 같은 이름이 나왔는데 초고·비류는 백제 왕명이라
가신 이름으로 쓰면 어색하다.

## 고증에 대한 입장

이 로스터는 **고증 재현이 아니라 게임 재미를 우선**한다. 700년을 50년으로
접고, 후삼국과 발해를 끌어오고, 설화 인물을 실존 인물과 나란히 세운 것이
모두 그 결과다.

다만 **어디까지가 사료이고 어디부터가 전승·창작인지는 데이터에 남겼다.**
`source` 필드를 보면 구분된다.

- `삼국사기` `삼국유사` `일본서기` `묘지명` `고려사` `신당서` → 사료
- `~(설화)` → 전승·야사
- `통칭(조선후기 문헌)` → 후대에 붙은 이름 (양만춘)
- `가상` → 창작

나중에 고증 모드를 만들고 싶으면 `source`로 필터링하면 되고,
`histAppear`/`histRetire`가 살아 있으니 실제 연표 배치도 가능하다.

위치나 실체에 이견이 있는 항목(목지국·남소성·황산벌 등)은 `note`에
"~로 전한다" 식으로 여지를 남겼다.

## 특기(skills)

현재 66종이 쓰이고 있다. 게임에서 전부 구현할 필요는 없다.
**상위 20종만 먼저 만들고 나머지는 플레이버로 두는 것을 권한다.**

가장 많이 쓰인 것부터: `governance`(26) `buddhism`(20) `valor`(18)
`forced_march`(17) `conquest`(13) `diplomacy`(13) `siege_defense`(13)
`navy`(12) `ambush`(12) `rearguard`(12) `raid`(12) `law`(12) `cavalry`(11)
`fortify`(11) `reform`(10) `insight`(10) `archery`(10) `strategy`(9) `siege`(9)

1급 인물에게만 붙은 고유 특기도 있다 — `flood_attack`(을지문덕, 살수대첩),
`last_stand`(계백), `hwarang`(김유신·사다함), `tang_diplomacy`(김춘추·김인문),
`martyr`(이차돈·관창), `spy`(도림). 이런 건 그 인물의 서사 자체이므로
남겨두면 좋다.

## 고치는 법

전부 `build_officers.py` 한 파일에서 관리한다.

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 핵심 인물 능력치 조정 | `T1` 리스트에서 해당 줄의 숫자 |
| 실존 인물 추가 | `T2`에 `(id, 이름, 세력, 등장, 은퇴, 역할, 격, 성향, 사료, 설명)` 추가 |
| 인물을 1급으로 승격 | `T2`에서 빼서 `T1`으로 옮기고 능력치 5개를 직접 지정 |
| 총 인원 늘리기 | `TARGET`과 `FILL_PLAN`의 숫자 |
| 역할별 능력치 성향 | `ROLE_BASE` |
| 등급별 상한 | `TIER_CAP` |
| 가상 이름 풀 | `SURNAME` / `GIVEN` |
| 특정 인물 시작 나이 | `AGE_FIX` |
| 세력 시작 군주 | `RULERS` |
| 나이 분포·차세대 비율 | `assign_age()` |
| 수명 | `assign_lifespan()` |

```bash
python3 build_officers.py   # → officers.json 재생성
```

난수 시드가 `20260815`로 고정되어 있어 **같은 입력이면 항상 같은 결과**가
나온다. 가상 인물이 매번 바뀌면 밸런싱을 할 수 없기 때문이다.
새로운 가상 인물 세트를 원하면 시드를 바꾸면 된다.
